# 🐱 Кошачьи дела — Менеджер задач

Современное веб-приложение для управления задачами с милым кошачьим дизайном.  
Проект реализован в **двух вариантах**: веб-версия (основная) и консольная версия на Python.

---

## 📸 Демо

🔗 **Живая демонстрация (GitHub Pages):**  
`(https://dally11001.github.io/murmur/)`

---

## ✨ Возможности

- ➕ Добавление задач
- ✅ Отметка задач как выполненных
- 🗑️ Удаление отдельных задач и всех выполненных сразу
- 🔍 Фильтрация: **Все · Активные · Выполненные**
- 💾 Автоматическое сохранение в `localStorage`
- 📱 Адаптивный дизайн под мобильные устройства
- 🎨 Современный UI с кошачьей тематикой
- 🛡️ Защита от XSS при выводе задач

---

## 🛠️ Технологии

**Веб-версия (основная):**
- HTML5 — семантическая разметка
- CSS3 — градиенты, анимации, кастомные чекбоксы, адаптивность
- JavaScript (ES6+) — работа с DOM, `localStorage`, фильтрация
- Google Fonts — шрифт `Nunito`

**Консольная версия (дополнительная):**
- Python 3.x
- Модули `json`, `os`

---

## 🎨 Особенности дизайна

- Тёплый персиково-розовый градиентный фон
- Кот 🐱 над карточкой с анимацией покачивания
- Узор из кошачьих лапок 🐾 на фоне (SVG)
- Кастомный оранжевый чекбокс с галочкой
- Мягкие пушистые тени и плавные анимации появления
- Кнопка с крутящейся лапкой при наведении
- Милое пустое состояние с котом 😺
